# 弹窗按钮与第三关背景修复

## 弹窗

预制体：`Assets/Prefabs/UI/SharedModal.prefab`。

设置的返回、胜利的下一关、失败的检查点重试，默认使用灰色边框与米白文字。悬停或键盘选中时显示青蓝色，退出悬停或取消选择后恢复。原始文字图片保留，通过 `Assets/Art/UI/Modal/NeutralLabel.mat` 转换默认文字颜色。

末关隐藏下一关后，重新挑战与返回选关在原按钮行内等距居中；重新打开前两关胜利界面会恢复原来的三个按钮位置。没有改动 GameplayHUD 和首页机器人、充电站排版。

## 第三关背景

预制体：`Assets/Prefabs/Levels/Level03_Map.prefab`。

- `SceneryLayers/FarCity` 跟随相机纵向移动；其他层保留纵向视差。
- `SceneryLayers/UpperTowerDecoration` 新增四个工业背景装饰，可在此手动调整位置、颜色与素材；它们没有碰撞体。
- 相机下面的 `DistantFactory` 增加 `CameraBackdropCover`，依据正交相机视口等比铺满，避免不同屏幕比例和爬升时留下背景空白。
- `SceneryParallax.verticalScrollRatio` 为 0 时完全跟随相机，为 1 时固定在世界中，中间值产生视差。

关卡平台、出生点、机关及碰撞布局保持原样。

## 验证

使用隔离 Unity 项目完成 22 项 UI 检查与 36 项运行时背景检查，包括默认/选中/恢复状态、末关布局及切回三按钮、三个高度的背景跟随、往返无漂移、4:3 和 16:9 铺满、装饰无碰撞。

报告与截图：`Artifacts/UIBackdrop/`。

重复应用工具（仅需要重新构建这两项时使用）：`InterfaceBackdropRevision.Run`。它会重建第三关的 UpperTowerDecoration，手动调整该组后请勿重复运行。
