# 界面设计与生图指南

## 1. 本阶段交付与使用方法

本阶段为界面设计，不是已能运行的 Unity 场景。用户先使用专业生图 AI 生成效果图，确定视觉后再搭建 Unity 界面、三个关卡与脚本。

已生成风格参考：[wasteland_style_reference_v01.png](../ArtSource/References/wasteland_style_reference_v01.png)。由内置 image_gen 生成，仅用于构图、机器人外形、材料与配色参考；细碎锈斑和明暗过渡应在正式版本中简化。图像不是可直接切片使用的正式素材，未做原生网格、精确色板和 PPU 验收。原始生成提示保存在 [style_reference_v01.txt](../ArtSource/Prompts/style_reference_v01.txt)。

## 2. 共同视觉与尺寸

- 游戏名：《锈境：能源重启》。Windows 横屏游戏，16:9。
- 设计坐标母版 640×360，原点左上；预览可用 1280×720 或 1920×1080，整数倍放大。
- 世界资产仍为 32 PPU；UI 使用屏幕坐标布局，不把面板宽度当成世界单位。
- 深灰钢板、锈橙少量结构、青色选中与能源色、危险红失败提示。参考色板见《像素美术规范》。
- 全部页面沿用相同方形切角面板、少量螺栓、按钮高度与边框厚度。像素装饰在逻辑母版中通常为 1～2 像素边框。
- 以连续色块表达体积；无渐变、写实高光、玻璃模糊、密集纹理和小字号装饰文字。
- 效果图中文字只是排版参考，正式中文由 TextMeshPro 排版；母版标题约 24～28 像素、按钮 12～16 像素、辅助说明至少 10～12 像素。
- 顶部/底部安全边距至少 24 像素。所有按钮保持明显轮廓，当前选中用青色边框和指示符共同区分，不能只靠颜色。
- 图中不得擅自加入生命、战斗、商城、账号、体力、广告、联网、Boss、技能树或第四关。

## 4. 选关界面：只做三关

顶部标题“选择关卡”，左上返回。三张关卡卡片水平排列，位置建议为 (32,80,176,212)、(232,80,176,212)、(432,80,176,212)。卡片内依次为编号、场景缩略图、名字、状态与记录。

| 卡片 | 名称 | 缩略图与重点 |
| --- | --- | --- |
| 01 | 废料回收区 | 锈蚀地块、废料箱、断裂管道；基础跳跃 |
| 02 | 废弃运输线 | 悬空铁架、移动平台、起重机；移动平台与巡逻 |
| 03 | 能源核心站 | 青色能源管、反应堆、终端；机制组合 |

首次状态：01“可挑战”，02/03“未解锁”，锁定卡片压暗并显示锁图标和“完成上一关解锁”。通关显示“已完成”；可以回选重玩。选中卡片青色外框和小指针。

效果图默认展示首次状态；卡片记录区使用“最佳时间 --:--”“最多收集 --/--”，不预填虚构成绩。底部主按钮“进入关卡”；锁定状态下禁用并显示说明。未选中时默认选第一张可挑战卡片。

## 5. 设置界面

使用中央钢板面板 (96,36,448,288)，顶部“设置”。只做能实际落地的选项：

- 音乐音量：水平滑条，0～100%。
- 音效音量：同样的水平滑条。
- 全屏显示：勾选框，切换全屏/窗口；不在第一版添加分辨率下拉和画质菜单。
- 固定操作说明：A/D 或方向键移动，Space 跳跃，Shift 冲刺，Esc 暂停。不提供尚未实现的改键功能。
- 底部“恢复默认”“返回”。设置即时生效并持久化；恢复默认只重置设置，不删除通关存档。

设置可以从主菜单和暂停页进入；返回原来源页面。游戏中打开设置保持暂停，返回暂停面板后按“继续游戏”恢复。关卡不直接在设置页后台运行。

## 6. 胜利界面

在当前关卡截图上覆盖平涂暗遮罩，中央面板 (112,44,416,272)。标题“关卡完成”，青色终端或扳手勾选符号；三行统计：“收集碎片 08/12”“通关时间 02:35”“死亡次数 3”。上述数字仅为效果图样例，不代表实际测试结果。

底部一排三个按钮建议各 112×32：“下一关”“重新挑战”“返回选关”。“下一关”为主操作。第三关完成时标题“全部关卡完成”，第一按钮改“返回选关”、第三按钮改“返回主菜单”，中间仍“重新挑战”。不使用无法解释的星级或经验奖励。

仅首次通关展示“已解锁下一关”；刷新纪录时另显示小标识，不一直展示。进入结算即停止计时和玩家输入，先保存进度再接受下一步操作。

## 7. 失败 / 重开界面

根据本次用户要求，调整前版“死亡后自动复活”的流程：死亡后显示失败弹窗，玩家自主选择重试。保留检查点，避免每次失败都从关卡起点开始。

背景为当前关卡冻结画面与纯色暗遮罩；中央面板 (144,48,352,264)，危险红仅用于标题和小状态灯，主要重试按钮仍青色。标题“机器人离线”，说明“可从最近检查点继续”。

四个纵向按钮：“检查点重试”“重新开始本关”“返回选关”“返回主菜单”。建议各 240×28，间隔 8 像素。第一次检查点尚未激活时第一按钮显示“起点重试”。

- 检查点重试：保留本次统计、已收集物状态和检查点；清空临时玩家效果；回到安全位置。
- 重新开始本关：清空本次关卡计时、死亡数与收集状态，从起点重新开始；已保存的历史成绩不清空。
- 失败界面不显示“得分为零”“游戏结束”或需要付费/广告复活等元素。
- 死亡发生时增加一次死亡计数；失败面板停留期间冻结本次计时，重试恢复。死亡表现的短暂延迟可继续计时。

## 8. 暂停弹窗

作为流程补全附带设计。冻结关卡背景加纯色暗遮罩，中央小面板显示“暂停”，按钮“继续游戏”“设置”“重新开始本关”“返回主菜单”。与失败界面使用同样的按钮素材，避免额外制作一套风格。

## 9. 从效果图到正式素材

专业生图 AI 每页输出一张效果图即可，尽量使用同一模型、参考图和种子保持风格。第一轮不要求分层和精确切片。

视觉确定后再生成：

1. 纯首页背景，无字无按钮。
2. 面板与按钮的无字独立 RGBA 素材，边缘留透明空间。
3. 普通/选中/按下/禁用四种按钮态；布局尺寸与边框一致。
4. 青色与灰色滑条、勾选框、锁、返回、能源碎片等图标。
5. 三关场景缩略图，不包含编号、关名或 HUD。

面板与按钮交给 Unity 9-slice 扩展时，保持边角像素尺度不变；只伸展平涂中心，不能把整张边框随意拉伸。具体 Sprite 切片和 border 数值在正式母版上量取，不从 AI 任意预览推断。

最终 UI 在 Unity 中拆成背景 Image、面板 Image、真正的 Button/Slider/Toggle 和独立文本；关卡世界则使用 Tilemap 与 Prefab。不要把整张效果图直接作为有按钮的游戏界面。
