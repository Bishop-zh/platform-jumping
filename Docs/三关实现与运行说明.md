# 三关实现与运行说明

> 2026-10-07 更新：供电已改为机器人内置电量和 E 充电器；旧电池库存规则与旧 C 交互说明已被替代。当前玩家摆放、Animator、充电与相机规格请以 [机器人动画与充电使用说明](机器人动画与充电使用说明.md) 为准。

打开 `Assets/Scenes/MainMenu.unity` 运行。主菜单开始游戏进入上次游玩的关卡；选关页允许选择已解锁地图。第 1 关默认开放，通关按顺序解锁下一关。

当前地图预制体、收集物数量、供电规则、Inspector 事件连线和所有组件的使用方法详见 [地图编辑与机关组件说明](地图编辑与机关组件说明.md)。三个场景引用 `Assets/Prefabs/Levels/Level01_Map.prefab`、`Level02_Map.prefab`、`Level03_Map.prefab`，修改预制体即可修改地图。

操作：A/D 或左右键移动，W/Space 跳跃，Shift 冲刺，E 交互，Esc 暂停。箱子由身体推动。机器人初始电量 20/100，E 操作充电器补能，机关首次供电通常扣除 40 电量，水晶不影响通关，终点无电量门槛。检查点重试保留收集及供电，整关重开恢复初始状态。

世界统一 32 PPU、Point、无 Mipmap、无压缩；相机原生 640×360 并整数放大，HUD 为对齐同一视口的 Overlay UGUI。近景、远景使用无碰撞视差组件。新地形保留橙锈、深色金属与青色能源的色彩，不再将整景强制压为旧 16 色调色板。

`Assets/Data/PlayerTuning.asset` 配置移动 4.5 U/s、重力 28、跳高 2.2 U、冲刺 10 U/s / 0.15 秒、冷却 1.2 秒，物理步长 0.02 秒。普通坑 2 U，推荐冲刺坑 3～3.25 U；修改能力后需重新测试间距。地刺下有坑底平台，浮台支架对齐承重位置。

后台验证结果在 `Artifacts/World/physics-validation.txt` 和 `asset-validation.txt`；实际 Unity 截图在同目录。验证使用受控输入和局部定位检查机制，不能替代编辑后的整关连续试玩。

玩家已绑定待机、移动、跳跃、冲刺、充电与死亡 Animator 状态；敌人专用动画仍可后续补充。`WorldBuilder.BuildAndCapture` 是开发用重建入口，会覆盖地图和生成预制体；用户开始手工编辑后不要直接执行它。

当前手工搭建、资源交接和导航验证请优先阅读 [手工关卡搭建与交接](手工关卡搭建与交接.md)。
