# 三关场景搭建设计 v01

> 2026-10-07 更新：供电已改为机器人内置电量和 E 充电器；旧电池库存规则与旧 C 交互说明已被替代。当前玩家摆放、Animator、充电与相机规格请以 [机器人动画与充电使用说明](机器人动画与充电使用说明.md) 为准。

本文件保留第一版距离计算与布局参考。实际三关物理已实现并通过后台 Unity 检查；当前电池供电、可选水晶、模块预制体与地图编辑规格见 [地图编辑与机关组件说明](地图编辑与机关组件说明.md)，该说明优先于本文件早期路线表。

## 1. 规模与制作顺序

三个关卡采用固定横向路线，每关约 1.5～2 个屏幕宽，避免做长地图再重复摆机关。有效宽度分别为 32、36、36.5 世界单位，主要活动高度为 0～4.5 单位；场景底部延伸至 y=-3。参考相机可见 20×11.25 单位，先做水平跟随，暂不做纵向卷屏。

每关包含一种突出机制、一个检查点、一个冲刺跳和一条短的额外收集路线。建议首轮通关时间约 45～90 秒/关；三关熟练游玩约 3 分钟，初次探索与重试约 4～6 分钟。时间为目标，需试玩调整。

先完成玩家灰盒与两种跳跃，再搭第 1 关并测试推箱和压板；第 2、3 关复用已经验证的组件。拼接美术最后覆盖灰盒，不让图上的装饰轮廓决定物理参数。

## 2. 玩家与跳跃距离

| 参数 | 首轮建议 |
| --- | --- |
| 行走速度 | 4.5 U/s，空中保持相同水平控制 |
| 物理重力加速度 | 28 U/s² 向下 |
| 起跳速度 | sqrt(2×28×2.2) ≈ 11.10 U/s 向上 |
| 理论最高脚底高度 | 2.2 U；固定步积分会略低 |
| 冲刺 | 水平 10 U/s，持续 0.15 秒，冷却 1.2 秒 |
| 冲刺竖向规则 | 不暂停重力，不清零竖向速度，继续正常抛物线 |
| 空中冲刺次数 | 每次离地最多一次；落地重置次数，冷却仍需结束 |
| FixedUpdate 步长 | 起步 0.02 秒 |
| 离地宽限 / 跳跃输入缓存 | 各 0.10 秒 |
| 玩家碰撞体 | 起步约 0.5×1.25 U；可视角色画布 1×1.5 U |

本版明确采用“只改变水平速度”的冲刺，替代早期方案中未明确的限制竖向运动。设计与实现不得一个冻结重力、另一个继续重力，否则同一张地图的距离会失效。以后若增加可变跳高，下面表格按完整按住跳跃测量；普通必经路线不能要求像素级起跳。

同高跳跃飞行时间 T=2×v0/g≈0.793 秒，普通水平距离 4.5×T≈3.57 U。一次冲刺取代原来的行走速度，增加 (10−4.5)×0.15=0.825 U，因此约 4.39 U。不能直接把普通距离再加 1.5 U，这会重复计算原本那段行走距离。

| 落点比起点高 | 普通理论距离 | 冲刺理论距离 | 推荐缺口 |
| --- | --- | --- | --- |
| 0 U | 3.57 U | 4.39 U | 普通 2 U；冲刺 3～3.25 U |
| 0.5 U | 3.35 U | 4.18 U | 普通 ≤1.75 U；冲刺 3 U |
| 1 U | 3.10 U | 3.92 U | 普通 ≤1.5 U；冲刺 ≤2.75 U |

表中的缺口指左右平台边缘之间的距离，不是平台中心距离。舒适路线按玩家在左边缘前 0.25 U 起跳、右边缘后 0.25 U 落地预留空间；这样净缺口还需加 0.5 U 才是中心移动距离。落地平台宽度至少 3 U，冲刺前预留至少 2 U 跑动区。常规台阶高差 0.5～1 U，箱子高 1 U，额外收集台高 1.5～1.75 U。

不能宣称 3.25 U 缺口物理上只能冲刺：贴边起跳、角色碰撞宽度和离地宽限可能让熟练玩家用普通跳越过。这里把它设计成从安全起跳位置推荐使用冲刺的挑战，允许技巧路线。如果后续确实需要强制冲刺，应加入明确的冲刺感应机关，而不是继续扩大缺口直到初学者只能极限操作。

`Tools/check_jump_design.py` 用连续公式和 0.02 秒半隐式积分计算，结果在 `Artifacts/LevelDesign/jump_reach.json`。这只确认数量级与安全余量；下一步仍要在 Unity 用实际碰撞体、输入、落地检测和冲刺时机实测。跳跃增强不是必经条件，1.2 倍起跳速度对应约 1.44 倍跳高，只用于额外碎片。

## 3. 关卡坐标与路线

坐标以关卡左端 x=0、普通地面顶面 y=0 为基准。区间 `[a,b]` 表示可站立顶面的左右边界；下方地形可填充至 y=-3。静态摆放通常对齐 0.25 U（8 个原生像素），普通地块仍按 1 U 网格拼接；小数边界用明确尺寸的平台预制体或裁切模块，禁止缩放 Sprite 来补长度。

### 第 1 关：废料回收区，32 U

顺序：安全起步 → 普通跳 → 推箱压板开门 → 检查点 → 冲刺跳 → 终端。

| 对象 | 坐标/尺寸 | 目的 |
| --- | --- | --- |
| 地面 A | x=0～6，顶面 y=0 | 出生点 (1.5,0)，小台阶 x=3～4、顶面 y=0.5 |
| 普通坑 | x=6～8，净宽 2 U | 坑底放尖刺，清晰显示不可走过去 |
| 地面 B | x=8～18，顶面 y=0 | 足够空间演示箱子、压板和门 |
| 推箱子 | 左下角 (10,0)，物理尺寸约 1×1 U | 水平推至重量压板 |
| 重量压板 | x=12～13，踩压顶面近 y=0 | 只识别可推箱的重量；外观附箱子符号 |
| 门与顶梁 | 门 x=14.5～15.5、y=0～3；顶梁 x=12.5～16、下沿 y=3 | 压板触发后锁存打开；顶梁阻止借箱子跳过门 |
| 检查点 | (16.5,0) | 已完成推箱谜题，失败后不用重做 |
| 冲刺坑 | x=18～21.25，净宽 3.25 U | 同高落点；危险只在坑内，不放在落点边缘 |
| 地面 C | x=21.25～32，顶面 y=0 | 落点至少留 3 U 安全区 |
| 额外收集台 | x=25～27，顶面 y=1.5 | 可借旁边箱子或普通跳拿碎片；不挡主路 |
| 出口终端 | 左下角 (29.5,0)，画布 2×3 U | 到达并启动后通关 |

推荐 8 个碎片：安全区 2、普通跳路线 2、压板后 1、冲刺路径 1、上层额外路线 2。碎片间距至少 0.75 U，不把所有碎片密集摆在地面。

### 第 2 关：废弃运输线，36 U

顺序：拉开关 → 启动移动平台 → 检查点 → 冲刺跨坑 → 躲巡逻机 → 终端。

| 对象 | 坐标/尺寸 | 目的 |
| --- | --- | --- |
| 起始地面 | x=0～7，顶面 y=0 | 出生点 (1.5,0)，拉杆中心 x=4 |
| 起重坑 | x=7～13，净宽 6 U | 不要求普通/冲刺跳硬跨；必须搭平台 |
| 移动平台 | 长 2.5 U，顶面 y=0；左端在 x=7.5～11.5 往返，速度 1.5 U/s，端点等待 0.6 秒 | 拉杆锁存启动；左端容易登上，右端与岸边搭接 1 U |
| 中部地面 | x=13～19，顶面 y=0 | 检查点 (16,0)，护盾拾取点 x=17 |
| 冲刺坑 | x=19～22.25，净宽 3.25 U | 同高跨越，落点不会立刻撞敌人 |
| 出口地面 | x=22.25～36，顶面 y=0 | 落点后的 x=22.25～24 为安全空间 |
| 巡逻机器人 | x=25～28，速度约 1 U/s | 一个敌人，只往返、不追踪；可跳过，护盾提供容错 |
| 额外收集台 | x=29～31，顶面 y=1.5 | 可选碎片，站立面明显 |
| 出口终端 | 左下角 (33.5,0) | 通关 |

推荐 10 个碎片，主路 7、起重机上层和额外台共 3。巡逻区域之外保留停靠和跳起空间。移动平台边缘接触必须测试，不用复杂加速度曲线；第一版不开垂直移动平台。

### 第 3 关：能源核心站，36.5 U

顺序：推箱供电 → 检查点 → 上升冲刺跳 → 按钮供电 → 同高冲刺跳 → 能源终端。

| 对象 | 坐标/尺寸 | 目的 |
| --- | --- | --- |
| 起始地面 | x=0～14，顶面 y=0 | 出生点 (1.5,0)；箱子 (3,0)，重量压板 x=5～6 |
| 初始门 | x=8～9、y=0～3；顶梁 x=6～10、下沿 y=3 | 压板激活供电 A 并锁存开门 |
| 检查点 | (11,0) | 保存已解锁供电 A 的运行状态 |
| 上升冲刺坑 | x=14～17，净宽 3 U | 右侧落点提高 0.5 U，仍保留余量 |
| 中间平台 | x=17～23.5，顶面 y=0.5 | 6.5 U 长，足够落地、走动和等待冷却 |
| 墙面按钮 | (21,1.5) | 靠近后按 E；锁存供电 B，电线/指示灯给反馈 |
| 第二冲刺坑 | x=23.5～26.75，净宽 3.25 U | 左右同高，不把冷却未完的玩家逼进连跳 |
| 出口平台 | x=26.75～36.5，顶面 y=0.5 | 两个落点均有安全站立空间 |
| 最终门 | x=32～33、y=0.5～3.5；顶梁 x=30.5～34、下沿 y=3.5 | 条件为供电 A AND 供电 B；复用同款门 |
| 能源终端 | 左下角 (34,0.5) | 从断电到激活两态，结束三关 |

推荐 12 个碎片，主路 8、可选高台 4。高台 x=18.5～20.5、顶面 y=2.25；跳跃增强放在 x=18 附近，可帮助拿额外碎片，但不用它也能走完整主路。首版不再加第三种新危险或新敌人。

## 4. 推箱、开关与机关的程序思想

第一版保持简单：只有可推箱、重量压板、拉杆/按钮、门、水平移动平台、指示灯。交互按钮统一按 E，进入范围时显示 UI 操作提示；与已建设置操作说明同步补充 E。跳跃、冲刺仍使用原有输入。

- `PushableCrate`：动态 Rigidbody2D，冻结旋转，只允许玩家以限速方式水平推；箱子可踩，不可携带，不做叠箱谜题。玩家冲刺撞箱子结束冲刺，避免把箱子击飞。
- `WeightPlate`：检测区域只统计 PushableCrate，不认玩家、碎片或特效。状态由实际重叠对象集合决定，不能用一个 OnTriggerExit 就直接清空整块压板。压下和松开两态。
- `LeverSwitch` / `WallButton`：靠近按 E，激活后保持供电到本关重开；同关最多一个需要交互的机关处于选中范围，避免同时触发。
- `SignalLatch`：第一次收到压板激活后锁存完成；灯变青、门保持打开。这样箱子回位或玩家重试不会把已解开的门重新关上。
- `SignalRelay`：第 3 关用两个明确输入实现 AND；不建通用节点编辑器，只做一个配置为 All 的简单组件。
- `GateController` / `MovingPlatform` / `IndicatorLight`：接收状态，各自更新碰撞、运动和表现；不直接读 UI，也不把门逻辑写进玩家脚本。

每段谜题的门、压板和接线用相同灯色与明显连接线配对；指示灯不依赖数字。门关闭时必须与视觉顶面对应；打开后禁用碰撞或物理上完整移开，不只换图片。

### 复活与防卡死

检查点重试：已收集碎片与锁存的供电/解谜标记保持；箱子、巡逻机、移动平台回到各自初始安全位置，移动平台的启用状态按锁存信号恢复。护盾/跳跃增强清除。第 1、3 关的检查点都放在推箱谜题后面，因此不会在解谜中途形成矛盾快照。

整关重开：清空本次碎片、锁存信号、计时、死亡数，重置全部对象。箱子区域没有可把箱子推下的坑；压板附近设置低矮挡块限位，减少永久丢箱。仍保留失败窗口的“重新开始本关”作为兜底。

不要用场景里散落的多个布尔值决定门状态。锁存标记归 `LevelRuntimeState` 管理；对象通过稳定 ID 登记，由 `LevelController` 统一重置。存档继续只保存通关成绩、解锁和上次关卡，不保存中途箱子坐标。

## 5. 可复用场景组件

| 组件 | 拼接方式 |
| --- | --- |
| 厚地面 | 顶边左 + 中 A/B/C + 顶边右；下方填充 A/B；外围侧边与底边 |
| 薄平台 | 左端 + 中 A/B/C + 右端，顶面一致；不按完整 PNG 留白做碰撞 |
| 金属支柱 | 顶帽 + 重复竖梁 + 底座；仅背景装饰，除非明确标成墙 |
| 护栏 | 左端 + 中段 + 右端；默认无碰撞，不误作脚下平台 |
| 电线 | 横直段、竖直段、四种转角、末端接头；沿机关之间拼接 |
| 移动平台 | 一个 2.5×0.5 U 面板，代码移动；运动轨迹和端点是场景配置 |
| 机关 | 同一个预制体更换初始状态和信号输入，不为每关复制脚本 |
| 远景 | 8×8 U 工厂轮廓横向拼接；保持 PPU=32、Scale=1；天空单独铺底色 |

中段变化只改内部锈迹和螺栓；左右各 2 个逻辑像素的边缘、顶面高度与阴影色完全一致。不能生成三张边缘不相同的板子再期待无缝。相邻中段按 A/B/C/A/C/B 等顺序混合，避免周期性条纹。

Scene hierarchy：Systems、Grid/Ground、BackDecoration、FrontDecoration、World/Mechanisms、World/Pickups、World/Hazards、Player、MainCamera、UICanvas。排序与碰撞层独立设置；背景、提示灯、电线没有物理碰撞。

## 6. 素材与验收入口

三关现已按本设计生成独立 Unity 场景；实际对象层级、组件职责、参数配置、运行入口和后台物理验证见 `Docs/三关实现与运行说明.md`。首批素材已归档并规范化为 32 PPU，远景暂时复用首页背景转换后的原生像素图，后续可替换为专用远景。

详细原生尺寸、每张图集的网格与占格安排、可复制提示词见 `ArtSource/Prompts/Scenes/场景素材生成提示词.md`，布局机器记录见同目录 `atlas_layouts.json`。

首批只生成地面/平台结构、机关、道具危险四张图集；装饰与远景后补。角色的跑跳冲刺动画另开批次，不能把首页机器人大图直接缩放后当作已满足 PPU 的世界角色。世界角色母版仍为 32×48，脚底锚点一致。

正式拼图先展示 6～8 段混合平台、机器人、箱子和门同屏：确认 1 U 物体是 32 个像素，2 U 是 64 个像素，图片无插值、素材单像素大小相同。还需测普通跳、起跳过早/过晚、冲刺左右方向、按住移动落地、头撞顶梁、箱子堵门、移动平台换向、检查点重试与重新开始。
