# 选关页面

## 资产和结构

- UGUI 预制体：`Assets/Prefabs/UI/LevelSelect.prefab`。
- 可直接编辑的预览场景：`Assets/Scenes/Preview/LevelSelectPreview.unity`。
- 运行入口沿用 `Assets/Scenes/MainMenu.unity`；首页“选择关卡”打开页面，“返回”回到首页，反复打开复用同一实例。
- 原始素材：`ArtSource/LevelSelect`；拆分记录：`slices.json`；切片工具：`Tools/prepare_level_select_art.py`。
- 真实 Unity 后台截图：`Artifacts/LevelSelect/initial.png`、`level2_unlocked.png`、`level3_unlocked.png`。解锁截图使用独立演示数据，不写入玩家存档。

页面使用 1672 × 941 参考尺寸、CanvasScaler、Point 过滤和 PPU 32，与首页及弹窗一致。标题、按钮、卡片、缩略图和中文文字分别放置。优先复用最后一张空白卡片，锁定卡片复用它的外框和空金属面，拆掉原图中不一致的重复空牌子；锁、提示牌、分隔线和文字为独立元素。无需额外生图。

三个 `LevelCardView` 使用同一组件，切换锁定／解锁内容，描边与箭头独立。首关默认解锁，初始第 2、3 关呈现锁定状态。锁定卡片不能通过鼠标、键盘或公开选择接口进入。

## 进度与选择规则

`LevelProgressRepository` 负责规则和存档，`LevelSelectView` 负责展示和事件，`MainMenuBootstrap` 负责首页导航。关卡编号统一使用 1、2、3。

打开选关页时优先选中新解锁关卡，否则选中上次进入的关卡；没有存档时选中第 1 关。玩家可以改选其他已解锁关卡，始终仅有一个青蓝描边。点击进入后记录该关并清除新解锁提示。第 1、2 关通关后依次解锁下一关，第 3 关不会产生第 4 关。

最佳时间与最多收集分别更新，可以来自不同次游玩。未通关时显示 `--:--` 和 `--/--`。数据以版本化 JSON 写入 PlayerPrefs 键 `Rustbound.LevelProgress.v1`，损坏数据回退到安全初始状态。后台验证采用内存仓库，避免污染真实玩家进度。

```csharp
using Rustbound.Progress;
using Rustbound.UI;

var progress = LevelProgressRepository.Load();
var view = Instantiate(levelSelectPrefab);
view.Show(progress);
view.LevelRequested.AddListener(LoadGameLevel); // 参数是 1..3 的关卡编号。
view.BackRequested.AddListener(ReturnToMainMenu);

// 后续游戏结算时调用；只有已解锁关卡可以结算。
progress.CompleteLevel(1, elapsedSeconds, collected, totalCollectibles);
view.Show(progress); // 第一次通关会选中新解锁的第 2 关。
```

运行入口的 `MainMenuBootstrap.LevelRequested` 会转发进入关卡事件，后续关卡加载器订阅此事件。当前实际关卡尚未搭建，点击进入会发送事件与更新进度，不假装加载一个不存在的游戏场景。

## 统一数字规范

页面没有使用新素材图集中的 01／02／03 或样例成绩图片。所有数字复用 `Assets/Art/UI/Modal/Digit0.png` ～ `Digit9.png` 以及 `Colon`、`Slash`、`Percent`、`Minus`，由 `SpriteNumberLabel` 动态拼接。短横线补取自已有数字源图，其余数字素材保持原样。后续 HUD、计时、收集、冷却、死亡数、百分比及所有新页面均必须使用同一套资源，不另引入数字字体。这条规则已写入项目方案和美术规范。

## 重建与验证

编辑器菜单 `Rustbound → UI → Rebuild Level Select` 重建选关预制体、预览场景，并补回首页连接。若先重建首页或弹窗，请最后重建选关页以重新连接入口。重建会替换生成资产，应先保存人工调整。

后台检查初始锁定、非法选择与结算、新解锁优先、上次游玩恢复、唯一描边、独立最佳成绩、存档往返、损坏存档回退、卡片／进入／返回事件、首页导航重复打开，以及数字资源复用和脚本／图片引用。报告见 `Artifacts/LevelSelect/validation.txt`。
