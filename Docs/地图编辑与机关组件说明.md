# 地图预制体与机关组件（2026-10-07）

> 2026-10-07 更新：供电已改为机器人内置电量和 E 充电器；旧电池库存规则与旧 C 交互说明已被替代。当前玩家摆放、Animator、充电与相机规格请以 [机器人动画与充电使用说明](机器人动画与充电使用说明.md) 为准。

## 直接开始编辑

三个入口场景分别为 `Assets/Scenes/Level01.unity`、`Level02.unity`、`Level03.unity`。每个场景引用一个完整地图预制体：

| 预制体 | 地图 | 充电器 | 可选水晶 | 主路线与供电用途 |
| --- | --- | --- | --- | --- |
| `Assets/Prefabs/Levels/Level01_Map.prefab` | 废料回收区，32 U | 2 | 8 | 普通跳 → 电池驱动推箱压板开门 → 检查点 → 冲刺跳 → 第二次供电开启检修门 → 终点 |
| `Assets/Prefabs/Levels/Level02_Map.prefab` | 废弃运输线，36 U | 3 | 10 | 电池驱动拉杆/运输平台 → 检查点 → 冲刺跳 → 两次供电开启检修门 → 终点；护盾和巡逻机器人增加变化 |
| `Assets/Prefabs/Levels/Level03_Map.prefab` | 能源核心站，36.5 U | 3 | 12 | 电池驱动压板开首门 → 检查点 → 上升冲刺跳 → 电池驱动按钮 → 冲刺跳 → 第三次供电开检修门 → 两路信号共同打开核心门 → 终点 |

双击地图预制体进入 Prefab Mode 编辑，保存后相应场景自动使用修改。也可以打开场景编辑实例，再将修改 Apply 回地图预制体。一个场景只保留一个完整地图；不要另外拖入第二套玩家、相机或 HUD。

根节点保留在 `(0,0,0)`、缩放 `(1,1,1)`。层级分为 `Systems`、`Terrain`、`Background`、`Mechanisms`、`Pickups`、`Hazards`、`Actors`、`UI`，另有 `SceneryLayers`、`SpawnPoint`。默认出生位置取 Player 摆放位置；使用 SpawnPoint 时勾选 LevelMap.useSpawnPoint。加长地图时修改 `Systems/LevelSession` 的 Width，相机会同步宽度；同时移动右边界、扩大 Void 触死区并延伸背景。

这些是可继续修改的起始地图，不是冻结的最终关卡。**编辑完成后不要再次执行 WorldBuilder.BuildAndCapture**：它是开发用重建工具，会覆盖三个地图模板及生成的预制体。

## 收集与供电规则

- 使用 `ChargeStation.prefab` 充电器，`Battery.prefab` 仅为旧引用兼容别名；`Fragment.prefab` 是可选水晶。
- 内置电量初始 20/100，充电速度 60/秒；HUD 显示电量、水晶收集比例、充电器访问比例，胜利界面显示后两者。
- WorldSignal 的 Battery Cost 保留旧字段名称，实际扣电量为 Battery Cost × Energy Per Battery。默认 1×40，0 表示免费，首次供电后不重复扣除。
- 充电器放在收费障碍之前的安全主路，允许反复补能。终点只检测玩家到达，不检查电量或访问充电器数量，水晶可以不拿。
- 检查点重试保留电量、收集和锁存供电；整关重开恢复初始电量与机关。详细路线和预算见 [手工关卡搭建与交接](手工关卡搭建与交接.md)。

## 拖入就能用的玩法预制体

位于 `Assets/Prefabs/World/`：

| 对象 | 预制体 | 绑定内容 |
| --- | --- | --- |
| 玩家 | `Player.prefab` | Dynamic Rigidbody2D、连续碰撞、角色碰撞箱、移动/跳跃/冲刺 |
| 推箱子 | `Crate.prefab` | Dynamic Rigidbody2D、箱体碰撞、旋转锁定；Travel Limits 为相对于摆放位置的左右推行范围 |
| 充电器、水晶 | `ChargeStation.prefab`、`Fragment.prefab` | E 补能/水晶拾取触发器、各自统计与重置 |
| 免费输入 | `Lever.prefab`、`WallButton.prefab`、`WeightPlate.prefab` | WorldSignal、开关状态图；压板触发区只接受箱子 |
| 电池输入 | `BatterySocket.prefab` | 首次扣除 40 内置电量发出信号，可修改 Battery Cost 和 Energy Per Battery |
| 门 | `PoweredGate.prefab` | 门碰撞箱、关闭/打开图，开启后禁用阻挡碰撞；约 0.35 秒响应时间 |
| 运输平台 | `MovingPlatform.prefab` | Kinematic Rigidbody2D、站立碰撞、乘员搭载；Travel Offset 为相对初始摆放位置的往返位移 |
| 敌人 | `PatrolEnemy.prefab` | Kinematic Rigidbody2D、触死区域；Patrol Distance 相对摆放位置，不再绑定旧地图坐标 |
| 检查点、终点 | `Checkpoint.prefab`、`Exit.prefab` | WorldZone Trigger、复活点/通关处理 |
| 危险 | `SpikeLeft.prefab`、`SpikeMiddle.prefab`、`SpikeRight.prefab` | 地刺图片及触死区域；底座必须放在地面或坑底平台上 |
| 增益 | `Shield.prefab`、`JumpBoost.prefab` | 临时护盾、跳跃增强拾取逻辑 |
| 整组示例 | `BatterySocketGateKit.prefab`、`CratePlateGateKit.prefab` | 输入与门已用持久事件连好；压板组另行放置可推箱子 |

输入组件不带电池消耗时，将 Battery Cost 设为 0；想让箱子压板也需要供电，可设为 1。默认机关一次开启后锁存。按钮/拉杆勾选 Toggle 后可反复开关，首次供电状态保留，不再扣除；压板仍保持一次锁存，避免箱子重叠触发反复开关。

### Inspector 连线方法

1. 放入一个 `BatterySocket` / `Lever` / `WallButton` 和一个 `PoweredGate`。
2. 在输入对象的 **World Signal → On Changed (Boolean)** 点 `+`，拖入目标门。
3. 选择 **Dynamic bool → GateController.SetPowered**。不要选择固定参数的 Static bool 项，否则关闭事件可能仍固定传入 true。
4. 使用事件控制时，门的 Input A / Input B 留空。平台同理选择 `MovingPlatform.SetPowered`，并将 Power 留空。
5. 同一个事件可以添加多个接收对象：一个开关同时开门、启动平台。其他脚本也可以提供 `public void 方法(bool)` 接收这个状态。

双输入 AND 门直接将两个 WorldSignal 拖入 GateController 的 Input A、Input B；有输入引用时门以这些输入为准，两个信号都开启才通电。单输入可只填 Input A。运输平台也可以直接用 Power 引用一个输入。这两种配置方式均已实现，选择其中一种即可。

交互键为 **E**；玩家脚底到机关距离小于 1.5 U 时操作最近的按钮/拉杆。压板由箱子接触触发，不响应 E。不要将功能对象放在近景/远景图层，交互对象应属于 Mechanisms。

## 新素材与碰撞

`Assets/Prefabs/World/Modular/` 提供 36 个地面、断桥、台阶、支架和平台模块；`Assets/Prefabs/World/Scenery/` 提供 5 个背景模块。

- 地面：`GroundWide_A/B`、`GroundLong`、`GroundRaised`、`GroundSteps`、`GroundLowStep`、`GroundCantileverLeft/Right`、`GroundCenterPier`、`GroundPier` 等。
- 桥：`BridgeLong_A/B`、`BridgeBrokenLeft/Right`、`BridgeSmall`、`BridgeThin`、`BridgeTwinSupports`、`BridgeCenterSupport`、`BridgeStairs` 等。`BridgeMovingDeck` 自带 Kinematic 移动组件，需连接供电信号。
- 支架：`ColumnNarrow`、`ColumnWide`、`ColumnTall`、`SupportArch`、`PierTall`、`PierDouble`、`PierSingle` 等。整件图片已有支撑时不再额外叠柱子。
- `CheckpointPlatform`、`BridgeCheckpointBase` 已带检查点区域；`ExitPlatform`、`TerminalPlatform`、`GroundExitBase` 已带终点区域，InteractionPoint 标记功能位置。
- 模块默认只碰撞可站立横梁，玩家能从梁下支架空隙经过。台阶和断桥使用分段碰撞，图片中的悬空断口不填整块矩形。若需要柱子本体阻挡玩家，可明确另加 BoxCollider2D；不要把图片透明范围全部填成实体。
- 部分整件素材画有箱子、压板或能源装置；除上面列出的检查点/终点/移动模块之外，这些画面细节属于装饰，不是可移动道具。要推箱或操作压板，使用独立功能预制体或已连好的 Kit，在布局中避开重复画出的道具。

可站立对象使用 WorldGround（8）/WorldPlatform（11）；玩家 WorldPlayer（9）；箱子 WorldCrate（10）；危险 WorldHazard（12）；普通触发器 WorldTrigger（13）。玩家落地检测包含地面、箱子、平台。开启 Scene 视图 Gizmos，选中对象检查绿色碰撞边线与可站立顶面是否一致。

### 背景与像素密度

`FarCity.prefab` 为远景，排序 -25、视差滚动比例 0.25；`NearScrapHeap`、`NearBrokenTank`、`NearCrane`、`NearCoreFactory` 为近景装饰，排序 -5、滚动比例 0.8。它们均无 Rigidbody2D 和碰撞体，不遮挡玩法碰撞。SceneryParallax 以 1/32 U 对齐横向移动，避免亚像素抖动；将 Scroll Ratio 设为 1 即保持世界位置不作视差移动。

全部世界精灵统一 **32 PPU**、Point、关闭 Mipmap、无压缩，物体缩放保持 1。例如 64 px 宽是 2 U，192 px 宽是 6 U，不能为了统一“物体大小”把长平台缩成短平台。平台视觉与物理长度分别由原生图片和 Collider 尺寸决定；拼接采用现有不同长度模块，不任意拉伸像素。世界画面使用 640×360 原生渲染并整数放大。

所有界面数字继续使用已经确定的 `Assets/Art/UI/Modal/Digit0…Digit9` 数字图片图集，由 SpriteNumberLabel 排列。HUD 新素材中的数字按钮不用于显示数值。

## 场景流程与验证

MainMenu → 开始/选关 → Level01/02/03；暂停设置返回后继续当前地图；失败可检查点重试或完整重开；胜利可下一关、重玩、返回选关或主菜单。第三关隐藏“下一关”。完成前一关自动解锁下一关，选关高亮使用已解锁的新关或上次游玩的关卡。

后台 Unity Play Mode 检查覆盖跳跃、冲刺、门阻挡、箱子压板、电池消费、空背包通关、重试、移动平台搭载及实际菜单/场景跳转。具体记录在 `Artifacts/World/physics-validation.txt`；世界素材和预制体引用验证在 `Artifacts/World/asset-validation.txt`。编辑地图之后，仍需手动完整走一遍主路，检查新距离、供电顺序和备用落脚点。
