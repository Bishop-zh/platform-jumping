# 修改碰撞箱后的落地与跳跃

角色控制脚本：`Assets/Scripts/World/PlayerMotor.cs`。

旧实现使用固定的 0.46 × 1.20 世界单位检测框，中心使用刚体位置加未缩放的碰撞箱 offset；它不适配修改后的角色 BoxCollider2D 尺寸、偏移或 Transform 缩放，并且排除了距离为零的命中。地面漏检会同时阻止跳跃并使动画停留在滞空状态。

现在优先检查实际物理接触，接触法线朝上才算落地；近地检测使用角色 BoxCollider2D 当前世界 bounds，自动跟随尺寸、偏移和缩放。实际支撑角色的非触发碰撞体不受手动更改的平台图层影响；空中预检测仍使用 PlayerMotor 的 Ground Mask。向上运动时不会重复判定落地。

选中角色、打开 Scene 的 Gizmos，可看到脚下黄色/绿色检测范围。PlayerMotor 的 Ground Probe Distance 默认 0.1，通常无需修改。

可站立的平台需要启用 Collider2D，且不能勾选 Is Trigger；纯 SpriteRenderer 图片不会产生物理支撑。装饰和机关触发区域与平台承重碰撞体应分开。此次没有自动修改任何地图、碰撞箱形状或界面排版。

隔离 Unity 工程验证：三种角色缩放、三种平台图层、修改后的角色碰撞箱尺寸/偏移、落地跳跃和上升状态，28 项通过。结果见 `Artifacts/World/ground-probe-validation.txt`。这验证了脚本行为；尚未操作用户正在编辑、可能尚未保存的地图。
