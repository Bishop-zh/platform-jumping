# 统一弹窗：设置、胜利、失败

## 已实现的资源

- `Assets/Prefabs/UI/SharedModal.prefab`：唯一弹窗预制体，包含共同底板、标题框、悬挂件、遮罩和三个内容分组。
- `Assets/Scripts/UI/Modal/`：弹窗切换、按钮事件、设置控件和共同打开动画。
- `Assets/Scripts/UI/Common/SpriteNumberLabel.cs`：数字与符号的精灵字符显示。
- `Assets/Art/UI/Modal/`：本次挑选并拆出的透明素材。
- `ArtSource/Modal/`：十张来源图与 slices.json 切分记录。
- `Assets/Editor/UI/ModalDialogBuilder.cs`：预制体/预览场景生成、后台渲染和验证。
- `Artifacts/Modal/{victory,failure,settings}.png`：真实 Unity UGUI 离屏截图；三张沿用同一个首页背景。

三个编辑预览场景在 `Assets/Scenes/Preview/`：ModalVictoryPreview、ModalFailurePreview、ModalSettingsPreview。它们引用同一预制体，只覆盖内容分组与标题；背景引用之前的首页预制体。正式 SharedModal 本身没有工厂背景、地形或机器人，打开时覆盖已有页面/游戏画面。

## 共用模板

```text
SharedModal：Canvas（sortingOrder=100）与 GraphicRaycaster
├─ Dimmer：全屏 46% 黑色遮罩，raycastTarget=true
└─ Composition：1672×941 参考布局
   ├─ LeftHanger / RightHanger
   ├─ CommonBody：共同底板
   ├─ CommonInset：共同内衬
   ├─ CommonHeader：共同标题框
   ├─ HeaderIcon / HeaderTitle：切换图标和标题
   ├─ VictoryContent
   ├─ FailureContent
   └─ SettingsContent
```

底板、标题框、挂件、画布缩放与遮罩不随状态改变。切换时三个内容分组互斥显示；共用 0.22 秒、72 像素位移的缓动下落动画，使用非缩放时间。编辑模式与截图直接显示最终位置。

底板选择空白底板资源，去掉与标题框重复的上部连接件；不使用内嵌不同文案的完整窗口图。设置参考图仅用于控件布局，其原有外框未采用。遮罩覆盖整个屏幕，无点击关闭行为；按钮区之外的点击也不会传到背景。

按钮从同一组图集中选择普通/青色素材，并使用 9-slice 保持边角和螺栓比例，适配胜利页短按钮与失败页长按钮。固定中文使用独立的 Image，真正的 Button、Slider、Toggle 负责交互。

## 字体处理

这批图中包含的是有限的中文词组和数字，不能据此获得完整中文字体。第一版使用固定词组图集，保留像素造型；缺少的失败标题/副标题/按钮词组从用户预览图按颜色提取为透明图片。底板、控件和背景均未从整张预览图烘焙成假界面。

数字 0～9、冒号、斜线和百分号拆成字符精灵。SpriteNumberLabel 会根据字符串动态组合，因此收集数、时间、死亡次数和滑条百分比不是固定的示例图片。现阶段不生成 TTF；需要更多中文时添加词组素材，或以后另选有完整字库的字体。

## 内容与行为

胜利：显示碎片、时间、死亡数、解锁提示；按钮发出 NextLevel、Replay、ReturnLevelSelect 事件。没有下一关时隐藏下一关按钮和解锁提示，保留重新挑战与返回选关。

失败：标题“机器人离线”，检查点提示与四个按钮，分别发出 RetryCheckpoint、RestartLevel、ReturnLevelSelect、ReturnMainMenu 事件。实际复活与场景切换由后续游戏流程接入。

设置：真实音乐/音效滑条、全屏勾选、操作说明、恢复默认与返回。默认音量 70%/80%，全屏默认开启；设置保存在 `Settings.MusicVolume`、`Settings.SoundVolume`、`Settings.Fullscreen` 三个 PlayerPrefs 键，不删除通关进度。

音量控件更新设置值与 SettingsChanged 事件，后续音频模块读取 MusicVolume/SoundVolume 应用到对应音源；当前没有音乐和音效系统，不伪称已完成混音。全屏切换仅在正式构建运行时应用，编辑器预览/后台截图不切换显示模式。

首页 MainMenuBootstrap 已增加可选 dialogPrefab 引用，MainMenu.unity 中连接到 SharedModal；“设置”按钮现在能打开该弹窗，返回关闭弹窗并恢复之前的选择。开始游戏与选关仍等待后续页面与关卡。

## 代码调用

```csharp
// dialogPrefab 为 Inspector 中连接的 SharedModal 上的 ModalDialogView。
var dialog = Instantiate(dialogPrefab);
dialog.Show(ModalMode.Settings);
// 同一个实例切换为胜利；数字来自真实运行统计。
dialog.ShowVictory(8, 12, 155f, 3, nextAvailable: true, newlyUnlocked: true);
dialog.Show(ModalMode.Failure);
dialog.ActionRequested.AddListener(HandleModalAction);
dialog.Hide();
```

调用方应管理自己的暂停、计时和游戏输入：本组件不直接改 Time.timeScale，不擅自冻结别的系统。遮罩与 UI 选择负责弹窗交互层；游戏流程打开结算/失败/设置时，应暂停游戏输入。导航调用方关闭或销毁时移除事件订阅。

编辑器菜单 `Rustbound → UI → Rebuild Shared Modal` 会重新生成此预制体、三个预览场景并重新连接首页入口；会替换生成资产，先保存人工调整。若先重建首页再重建弹窗，弹窗生成工具会补回首页引用。

## 验证

后台独立工程编译及渲染，不改变前台窗口。检查三个内容互斥、共同底板的位置/尺寸不变、动态数字、按钮事件路由、滑条刷新、默认值恢复、遮罩拦截和脚本/Sprite 引用。检查结果记录于 Artifacts/Modal/validation.txt；同步回原项目后另检查 GUID 引用与截图背景一致性。

这是首版 UI，未包含后续关卡中的复活、胜利解锁或完整音频模块。

布局修正：共同底板上沿延伸至标题框后方，避免素材透明留白造成透底空隙。设置区域采用 70px 行距，操作说明和底部按钮上移；底部按钮下沿为 735px，保留框内边距。后台验证同时检查设置按钮完整位于底板内侧。

操作说明调整：删除说明区域独立底框与标题图中的金属底板，说明采用两列两行（移动／跳跃、冲刺／暂停），所有文字按素材原始宽高比等比例显示。
