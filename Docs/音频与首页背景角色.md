# 音频、相机呈现与首页背景角色

## 音频已自动接入

三个原创合成音频位于 `Assets/Audio/`，44.1 kHz、16 位双声道 WAV：

| 文件 | 用途 | 时长 |
| --- | --- | --- |
| UI_Click.wav | 菜单、HUD、弹窗等按钮点击，短促机械电子声 | 0.13 秒 |
| Wasteland_Play_Loop.wav | 关卡背景音乐，112 BPM，轻快芯片旋律、低频贝斯和工业鼓点 | 34.29 秒循环 |
| Victory.wav | 通关胜利，机器人电子音色的上升短曲 | 3.1 秒 |

程序启动自动创建场景对象 GameAudio，跨场景保留一份，包含独立 Music 和 Effects AudioSource、一个 AudioListener。音频引用集中在 `Assets/Resources/GameAudioBank.asset`，可以直接替换音频，不需要改脚本。音乐流式读取，两个短音效加载到内存。音频由 `Tools/generate_game_audio.py` 原创合成，未使用第三方曲目或采样。

进入关卡自动循环背景音乐，通关停止背景音乐并播放胜利音效，重玩恢复背景音乐，返回首页停止关卡音乐。按钮在运行时自动获得点击监听；暂停时仍能播放按钮音效。GameAudio.Update 只使用不受 Time.timeScale 影响的扫描间隔。

设置面板“音乐音量”只控制 Music，“音效音量”控制 Effects，包括点击和胜利；滑块立即生效，设置使用 PlayerPrefs 持久保存，恢复默认恢复 70%/80%。本次未调整设置面板或 GameplayHUD 排版。

## 无摄像机提示修复

此前世界相机只输出 RenderTexture，Unity Game View 没有直接面向 Display 的摄像机，因此显示“无摄像机”。WorldCamera 现在同时创建 GameViewCamera（直接输出屏幕，不绘制世界物体），世界仍由像素 RenderTexture 和 Overlay 画布呈现。相机及呈现画布随关卡销毁，下一关重新创建。

GameAudio 统一提供监听器，禁用当前场景其他监听器，避免重复 AudioListener。普通地图及首页无需手工再加监听器。

## 可编辑的首页角色预制体

`Assets/Prefabs/UI/MainMenuBackdropActors.prefab` 是独立的首页背景装饰组，子对象 Robot 和 ChargingStation 保留原来的图片帧动画。它是首页背景的 UGUI 装饰，不是可操控的世界玩家，也没有碰撞。

首页模板 `Assets/Prefabs/UI/MainMenu.prefab` 的 Composition 内放置该预制体实例。可以在首页 Prefab Mode 中移动两个子对象；想统一修改模板时 Apply 回 MainMenuBackdropActors，也可以直接编辑该预制体。

两个对象锚点位于背景设计画布左上角，当前脚底基线为距画布顶部 681 像素。MainMenuBackdropActors.platformTop 是人工对齐辅助参数；右键组件执行“将角色脚底对齐平台高度”即可重新对齐。运行时不会强制重置你修改的位置。

运行时该组被放到 FullScreenBackground 下面，与平台图片共享设计坐标、缩放和中心，绘制于背景平台之后、标题按钮之前。屏幕缩放时它们与平台一起缩放，不会跟着前景控件层而偏移。没有创建第二套角色副本。

原首页的按钮、标题及 GameplayHUD 没有重建。更换背景平台图后，如果平台高度变化，可手动调整角色组及 platformTop。

验证报告：`Artifacts/Audio/runtime-validation.txt`、`asset-validation.json`；验证覆盖首页分层、脚底对齐、两套动画、单相机屏幕输出、单监听器、音量分流、静音、恢复默认与重玩音乐恢复。
