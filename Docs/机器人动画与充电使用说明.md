# 机器人动画、内置电量与长卷轴相机

本说明替代上一版“拾取电池放入背包”的供电规则。水晶仍为可选收集物。

## 直接使用

拖入 `Assets/Prefabs/World/Player.prefab`，将 Transform 放在希望出生的地面位置，缩放保持 `(1,1,1)`。该坐标为机器人脚底，运行时会自动成为本关起点；相机自动绑定并立即显示这里。

在已有地图中推荐删除原 Player，再拖入新 Player；在地图外新增的玩家会优先绑定到现有 LevelSession，并禁用旧玩家，避免双重控制。若需明确指定标记点，将 PlayerRigBootstrap 的 Spawn Override 拖入一个 Transform。地图根 LevelMap 的 Use Spawn Point 默认关闭；勾选后使用地图 SpawnPoint，优先级高于直接摆放坐标。

新场景不需要手工创建玩家管理器和跟随相机：预制体会创建简单的 standalone 会话并绑定现有主相机，缺少相机时自动创建；不会写正式关卡进度。新场景仍需要地面 Collider2D，例如 Modular 中的平台。没有结算 UI 的 standalone 场景死亡后自动回到起点；正式三关先播死亡，再显示失败窗口。

## 控制与物理

| 输入 | 行为 |
| --- | --- |
| A / D、左右方向键 | 水平移动 |
| W / Space | 地面跳跃 |
| Shift | 水平冲刺，保留竖向重力 |
| E | 对附近最近的充电器充能，或向按钮/拉杆投入电量 |
| Esc | 正式关卡暂停/继续 |

S 不作竖直移动；本版本为横向平台游戏。角色绑定 Dynamic Rigidbody2D、连续碰撞、冻结旋转和脚底基准的 0.5×1.25 U BoxCollider2D。移动参数继续使用 `Assets/Data/PlayerTuning.asset`，没有改变先前的跳跃距离和冲刺冷却。落地检测包含 Default、WorldGround、WorldCrate、WorldPlatform，可在 Ground Mask 修改。

## Animator 状态机

`Assets/Animations/Robot/Robot.controller`，参数 `Mode:int`、`Dead:bool`；PlayerPresentation 根据实际物理速度、落地、冲刺、充电和死亡更新状态。

| Mode | 状态 | 动画来源 |
| --- | --- | --- |
| 0 | Idle | 24 帧待机，循环 |
| 1 | Run | 24 帧移动，循环 |
| 2 | Rise | 跳跃图起跳/上升段 |
| 3 | Fall | 跳跃图下落段 |
| 4 | Dash | 移动姿态加速播放及已有冲刺残影 |
| 5 | Death | 24 帧倒地，1.5 秒，不循环 |
| 6 | Charging | 待机姿态；充电器使用 4 档电量帧 |
| 7 | Land | 跳跃图落地段，约 0.2 秒 |

Sprite 动画不移动 Rigidbody 根节点，物理运动始终由 PlayerMotor 决定。动画过渡为即时切换，避免像素精灵混合。死亡立即停止输入与物理，Animator 使用未缩放时间播放倒地，再打开失败窗口；暂停时普通动画停止。复活恢复物理和状态。

素材原图保存在 `ArtSource/Robot`。待机帧中第 12、14、16、22 帧（从 0 开始）已翻正，其余帧保留；运行时按朝向统一 flipX。96 张角色帧采用同一缩放和 64×64 原生画布，充电器 4 帧为 64×96；全部 32 PPU、Point、关闭 Mipmap、无压缩。原图的黑色外背景已做连通区域清除，保留封闭的机身暗色区域；倒地帧脚底统一对齐地面。

## 内置电量与充电器

拖入 `Assets/Prefabs/World/ChargeStation.prefab` 到地面。靠近 1.5 U 内按 E 开始充电，默认每秒恢复 60，充满后停止；移动离开、死亡或暂停时中断。可以反复充电，不消耗地图上的道具。充电器提供 `On Charged` 事件用于满电后的联动。

Player 上的 RobotEnergy：Capacity 默认 100，Initial Charge 默认 20。初始电量不够驱动默认 40 电量的机关，但普通移动、跳跃和冲刺不受电量限制，避免低电量后无法寻找充电器。

既有开关事件接口保留：WorldSignal 的 Battery Cost × Energy Per Battery 为首次供电所需电量，默认 `1 × 40`。字段名保留是为了兼容已经绑定的机关；它现在代表消耗内置电量，而非拿走一个背包电池。电量不足不会改变机关，触发 On Insufficient Power；成功供电保持安装，反复按键或切换不会重复消耗。检查点重试保留电量与已供电机关；完整重开恢复初始电量。

门/平台仍通过 `On Changed(bool)` → Dynamic bool 的 `SetPowered` 连线，或使用原先的单输入/双输入引用。终点仅检测玩家到达，不检查剩余电量。

HUD 显示当前电量百分比、当前电量数值和水晶已收集/总数；胜利页显示充电器使用数/地图充电器总数和水晶比例。每台充电器首次使用计一次，重复充电不重复计数。数字继续使用既有 Modal 数字图片图集。

原三关的拾取电池已在原位置换为充电器，地形与机关布局保留；分别为 2、3、3 台充电器，水晶仍为 8、10、12。旧 `Battery.prefab` 已作为兼容入口转换为充电器，新增地图请使用命名清晰的 ChargeStation。

## 相机与检查

WorldCamera 使用 640×360 Point 画面与整数倍显示。正式地图开启 Bounded 时按地图 Width 限制横向中心；地图小于一个屏幕也能正确取中。增加长卷轴长度时修改 LevelSession.Width 并延伸地形与触死区；相机同步宽度。Standalone 自动关闭边界并开启 Follow Vertical，允许在任意世界位置搭建测试地图；正式关卡也可按需要关闭 Bounded 或开启纵向跟随。

`Artifacts/Robot/validation.txt` 为此次实际后台 Unity Play Mode 检查，覆盖动画状态、左右朝向、跳跃/冲刺物理、充电、重复供电、死亡复活以及远处出生点的自动相机绑定。此前 World 的报告为上一版电池拾取机制的历史验证，不代表当前充电机制。

`RobotUpgradeBuilder.Build` 用于开发时更新角色与充电器，不重新生成地形。它仍会将模板中的旧电池转为充电器；手工编辑后不要执行整关 WorldBuilder 重建。修改地图之后需要完整试玩以确认充电器位置、交互距离和各段电量预算。


## 黑描边修复与素材位置

角色原始待机/移动/跳跃/死亡图集是黑色不透明背景，纯黑背景与外轮廓相连，RGB 去背景会误删描边。当前切片流程保留已有不透明颜色，并在 64×64 原生分辨率恢复一像素深色轮廓，修复小的黑色接缝孔洞。已有真实 Alpha 的图片直接保留透明信息，不再按黑色去除。执行 `Tools/prepare_robot_art.py --robot-only` 仅更新 96 张角色帧，不重建 UI、充电器或碰撞。

- 实际使用帧：`Assets/Art/Pixel/Robot/`，Idle00～23、Run00～23、Jump00～23、Death00～23；64×64、32 PPU。
- 原始整图：`ArtSource/Robot/Idle.png`、`Run.png`、`Jump.png`、`Death.png`；Charge.png 是充电器原图。
- 角色预制体：`Assets/Prefabs/World/Player.prefab`，在此编辑 BoxCollider2D 与 Rigidbody2D；地图实例已有 Override 时，请另外核对实例。
- 动画：`Assets/Animations/Robot/Robot.controller` 和同文件夹 .anim，引用仍保留原 GUID，无需重新拖帧。
- 地形图片：`Assets/Art/Pixel/World/`；带碰撞模块：`Assets/Prefabs/World/Modular/`；近远景：`Assets/Prefabs/World/Scenery/`。
- 三张完整地图：`Assets/Prefabs/Levels/Level01_Map.prefab`、`Level02_Map.prefab`、`Level03_Map.prefab`。

本次只修改角色纹理与处理脚本，碰撞配置未改动。描边检查报告见 `Artifacts/Robot/outline-validation.json`，预览见 `Artifacts/Robot/AnimationFrames.png`。
