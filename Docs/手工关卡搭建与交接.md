# 手工关卡搭建与交接（2026-10-07）

本文是当前规则的交接入口。旧文档中的电池背包、C 交互和缺少玩家动画说明已被内置电量、E 交互和 Animator 替代。

## 编辑入口

三个地图预制体分别为 `Assets/Prefabs/Levels/Level01_Map.prefab`、`Level02_Map.prefab`、`Level03_Map.prefab`；对应场景为 `Assets/Scenes/Level01.unity`、`Level02.unity`、`Level03.unity`。在 Prefab Mode 编辑并保存，场景自动使用修改后的地图。不要执行 WorldBuilder 全量重建，会覆盖手工摆放。

保留 LevelMap、LevelSession、HUD、相机和唯一 Player。地形放 Terrain，收集物放地图根节点下的 Pickups，机关放 Mechanisms，背景放 Scenery。水晶总数由地图内启用的 Fragment 自动统计；充电器总数由场景内启用的 ChargeStation 统计，HUD 和胜利界面同步显示。增删对象后重新运行核对总数。

默认以 Player 摆放位置为出生点；想使用 SpawnPoint，勾选 LevelMap.useSpawnPoint 并绑定 Transform。替换玩家时删除旧 Player，拖入 `Assets/Prefabs/World/Player.prefab`。地图长度变化后设置 LevelSession.width，相机由此限制水平范围。

## 当前能力与规则

A/D 或左右键移动，W/Space 跳跃，Shift 冲刺，E 充电或操作机关。移动 4.5 U/s，跳高 2.2 U，重力 28；冲刺 10 U/s 持续 0.15 秒，冷却 1.2 秒。普通同高坑优先 2 U，跳跃冲刺坑 3～3.25 U；量平台边缘净间距，保留落脚余量。此范围是布局建议，须实际从出生点连续试玩验证。

机器人出生电量 20/100，充电器每秒补 60，可重复使用。供电机关建议消耗 40，只在首次供电扣除。移动、跳跃、冲刺不扣电。充电器必须在收费机关上游的安全位置；终点只检测玩家进入，完全没有“背包有几块电池”的门槛。水晶是可选探索奖励。

普通重试保留电量、已收集水晶和锁存供电，箱子等物体回到初始位置；整关重开恢复初始状态。压板目前为箱子触发、锁存模式，移走箱子不会关闭门，不是持续站压开关。

### 第一关：短路线教学

出生安全平台 → 充电器 → 2 U 小坑 → 箱子与压板 → 第一扇门 → 检查点/备用充电器 → 3～3.25 U 冲刺坑 → E 按钮与第二扇门 → 终点。

参考横坐标：起点地面 0～6；中段 8～18；末段 21.25～32。箱子约 10、压板约 12.5、门约 15；检查点约 16.5；末段按钮约 22.5、门约 24、终点约 30.5。付费压板或按钮配置 40，另一教学压板可免费，实际总收费控制在 80。

8 个水晶分成主路 4、箱子上方支路 2、末段高台 2；可选高台不承担开门条件。第一充电器充满后足够两次供电，第二个作为重试与探索补给。

### 第二关：运输与补给

出生充电器 → 拉杆驱动运输平台 → 检查点与第二充电器 → 冲刺越坑 → 供电按钮开门 → 安全补给点 → 第三次供电 → 终点。

参考地面分段 0～7、13～19、22.25～36。7～13 的大坑禁止直接要求裸跳，使用移动平台跨越；平台宽约 2.5～4 U，水平行程根据实际落脚点设置。19～22.25 是跳跃冲刺净坑。补给点须位于最后收费按钮之前，避免电量不足时被单向门困住。

3 次供电共需 120，至少中途再补一次电；3 个充电器分布起点、检查点、后半段安全区。10 个水晶主路 5、运输平台附近支路 3、末段上层 2。敌人与充电器留出安全距离，检查点不放在敌人巡逻路径上。

### 第三关：两路能源核心

起点充电 → 箱子压板提供核心输入 A，并开启前门 → 检查点补给 → 高低平台段 → E 按钮提供核心输入 B → 末段补电 → 检修门供电 → 已获两路信号的核心门 → 终点。

参考分段 0～14、17～23.5、26.75～36.5。前门约 8.5，检查点约 11；中段按钮约 21，安全充电器约 22.5；末段检修按钮约 27.5、检修门约 29、核心门约 32.5、终点约 35。核心门同时引用压板和中段按钮，门本身不额外扣费。

三次收费合计 120，补给必须可达。12 个水晶主路 6、上层支路 4、末段绕行 2。上层探索路线可提高难度，但主线不要依赖未收集的跳跃增强道具。

## 可直接使用的组件

`Assets/Prefabs/World`：Player、ChargeStation、Crate、Lever、WallButton、WeightPlate、BatterySocket、PoweredGate、MovingPlatform、Checkpoint、Exit、Fragment、SpikeLeft/Middle/Right、PatrolEnemy、Shield、JumpBoost。Battery 是兼容旧引用的充电器别名，新地图使用 ChargeStation。

按钮/拉杆的 WorldSignal.onChanged 添加目标实例 → GateController.SetPowered(bool) 或 MovingPlatform.SetPowered(bool)。收费设置 batteryCost=1、energyPerBattery=40；免费设置 batteryCost=0。单事件控制的门清空 inputA/inputB；两路核心门直接赋 inputA/inputB，要求两个 Active 同时成立。可以用现成 BatterySocketGateKit、CratePlateGateKit 查看连线。

Modular 下是带地形碰撞的可拼接模块，Scenery 下是无碰撞的近远景。整张复合平台素材中画出的箱子、灯、压板不一定是独立交互物，功能机关请使用对应预制体，不能把“画了按钮”等同“有事件”。

## 视觉和碰撞验收

世界素材 32 PPU，Point、无 Mipmap、无压缩，Transform scale 保持 1。不同宽度素材自然占不同世界长度，不把不同大小图片统一拉成相同宽度。支架属于装饰时不要添加阻挡玩家的满矩形碰撞。

优先完整地面模块；浮台短台用一根居中支柱，长台用两根对齐承重点的支柱，不逐格加柱。柱脚接实地，地刺底座紧贴真实坑底平台；切勿悬空。台阶按可走表面分段碰撞，检查顶面连续、接缝不绊脚、门关闭时不能从上下绕过。

远景城市置于后层，近景废料置于前层或平台后层，用 SceneryParallax；均不加碰撞。控制近景遮挡，不遮住玩家、落点或红色危险物。现有素材有复合模块和独立组件混合，需要你根据接缝与承重观感挑选，尚未保证所有素材能无缝互拼。
