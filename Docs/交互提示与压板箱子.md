# 交互提示、压板与箱子

首页机器人与充电站保留用户已修改的位置，本轮不修改首页脚本、预制体或位置。

## 角色上方文字

运行时自动为玩家创建 PlayerHint，位置跟随碰撞箱顶部，显示暖米黄色（RGB 253/216/167，与原数字图集主色一致），带深色文字描边，无底板。字形使用 Windows 的 Microsoft YaHei/SimHei 动态字体；当前 Windows 编辑器和 Windows 构建可用，移植到其他系统时需配置支持中文的字体。

- 靠近未充满电的充电器：按 E 充能。
- 正在充电：正在充能…；满电：电量已充满。
- 靠近需要供电的机关：按 E 消耗能量开启开关。
- 靠近免费手动机关：按 E 操作开关。
- 电量不足操作失败：电量不足，请先充能。
- 首次触发检查点：存档成功，显示两秒；整关重开后可再次触发。

提示与 E 交互使用相同的近距离范围，死亡与暂停时隐藏。它是独立的运行时文字层，不修改 GameplayHUD 排版。若消息正在显示，优先显示短消息，随后恢复靠近物体的提示。

## 压板规则

WorldSignal.plate=true 的地面压板现在由玩家或箱子触发，不需 E，不消耗电量，即使旧地图保存的 batteryCost=1 也不会扣电；运行时将压板费用置为 0。

默认至少有一个有效重量压住时开启，全部离开时关闭。onChanged 仍输出 bool，可直接连接 GateController.SetPowered 或 MovingPlatform.SetPowered。多个玩家碰撞体/箱子使用集合跟踪，不会因为其中一个离开就错误关闭。

新选项 latchPlate 默认关闭。如你的谜题需要踩过一次就永久开启，可勾选它；普通压板推荐保持默认，用箱子保持开启。检查点重试会清除非锁存压板的踩压状态，箱子回到原位；已付费的手动能源机关保持原来的重试供电规则。

压力按钮与手动能源开关为不同交互：前者免费踩压，后者靠近 E 操作，是否收费由 batteryCost×energyPerBattery 控制。

## 箱子与角色颜色

PushableCrate 在运行时设置抓地材质（默认摩擦 0.65、弹性 0），质量至少 3、阻尼至少 4。maxPushSpeed 默认 2.4 U/s，stopDeceleration 默认 18 U/s²；落地且没有玩家从侧面推动时主动减速。可以在组件 Inspector 调整三个新参数。碰撞箱尺寸和摆放位置没有修改。

原青蓝色是 PlayerMotor.Shield 的染色显示，不是存档点设置的颜色。现已去掉整体染色，角色保持原贴图颜色，护盾抵挡一次伤害的逻辑保留。
